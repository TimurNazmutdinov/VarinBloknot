1. Прочитай ТЗ.md целиком. Картинки из design/screens открывай только при сверке.
2. Дай короткий план этапа 1 (5–8 пунктов) и дождись моего «ок». Спроси имя моего GitHub-аккаунта.
3. Сделай этап 1: проект Kotlin + Jetpack Compose в C:\Projects\VarinBloknot, сцена 1 по макету (данные из scenes/scene_01.json) и автообновление через GitHub (контент + APK), release-ключ и publish.ps1.

Дальше этапы — только после моего подтверждения. Без лишних библиотек и больших загрузок; если нужно что-то скачать — спроси.
