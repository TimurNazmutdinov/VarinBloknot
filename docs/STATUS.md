## Версия 0.2.0: новая графика (art_v2 → content/art)
Подключено по `art_v2/ТЗ_графика.md`:
- Сцены 1–3 собираются из слоёв по `layers.json` (порядок, x/y/w/h, масштаб k = ширина/1600, Crop на весь контейнер). Слои загружаются один раз на сцену. `full.webp` — превью/карточки/список.
- Перекраска: слой с `tint` заменяется на `<имя>_tint.webp` с `ColorFilter.tint(цвет, Modulate)`. Перекрашиваются quilt, curtains, rug, pillows (в сценах 2–3 — шторы).
- Нажатие определяется по непрозрачному пикселю слоя (сверху вниз). Щипок — приблизить, палец — двигать.
- Покупка (сцена 1, бюджет 5 000 ₽): Лампа → lamp+lampglow, Полка → shelf, Коврик → rug, Шторы → curtains. Пока не куплено — слой скрыт, на его месте пунктир с ценой. «Обои» — только отметка (отдельного слоя нет). Предметы можно убрать и вернуть деньги.
- В сценах 2–3 цен нет: предметы видны сразу, привязки: Копилка → piggy, Стакан → cup, Скатерть → table, Миска → bowl, Банки → shelf; «Наклейки» без слоя.
- Герои: слой `varya` на «Живой сцене» скрыт, герои из `characters/` по `relHeight`, Варя ≈ 37% высоты кадра. Положение героев — поле `stage` в JSON сцены (доли кадра), подобрано на глаз.
- «Живая сцена»: пузырь над головой говорящего, камера (наезд ×1.5), дыхание кадра; реплики подставляют выбор игрока ({bought}, {left}, {spent}); в сцене 1 Варя сама выбирает ответ (поле `choices`); список реплик — по кнопке ☰.
- Задание «Уложись в 5 000 ₽» стартует с тем, что игрок купил.
- Убрано: свободная раскраска мазками и полноэкранная раскраска (раскраска теперь — перекраска готовых слоёв).
