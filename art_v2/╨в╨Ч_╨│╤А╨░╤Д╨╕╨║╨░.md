# ТЗ: новая графика «Варин блокнот» (версия 0.2.0)

## Задача
Заменить графику сцен 1–3 и героев на этот комплект. Стиль утверждён, рисунки не менять и не перерисовывать. Логика игры из docs/STATUS.md (раздел «Решения») остаётся. В этом этапе только подключение графики.

## Что в комплекте
- `scene1_room/`, `scene2_desk/`, `scene3_kitchen/`:
  - `full.webp` — готовая картинка сцены 1600×1000, для превью и запасной вариант;
  - `layers/*.webp` — предметы, каждый на прозрачном фоне и обрезан по краям;
  - `layers.json` — порядок слоёв (снизу вверх) и место каждого: `x`, `y`, `w`, `h` в пикселях кадра 1600×1000. У перекрашиваемых слоёв есть поле `tint`.
- `characters/*.webp` — герои по отдельности, `characters.json` — относительный рост и точка опоры (середина между стоп). `_all.png` — лист всех героев, только для просмотра.
- `source/` — исходники рисунков. Для сборки не нужны, не открывать.

## Как собрать сцену
1. Контейнер с пропорцией 16:10. Масштаб `k = ширина контейнера / 1600`.
2. Слои рисуются по порядку из `layers.json`, каждый в точке (`x·k`, `y·k`), размер (`w·k`, `h·k`).
3. Обрезка экрана — `ContentScale.Crop` на весь контейнер, а не на отдельные слои.
4. Картинки загружать один раз и держать в памяти, пока открыта сцена.

## Перекраска (шаг «Оформление»)
- Если у слоя есть `tint`, то при выборе цвета вместо слоя рисуется `<имя>_tint.webp` с `ColorFilter.tint(цвет, BlendMode.Modulate)`. Без выбранного цвета показывается обычный слой.
- Перекрашиваются: `quilt` (одеяло), `curtains` (шторы), `rug` (ковёр), `pillows` (подушка).
- Нажатие на предмет определять по непрозрачному пикселю слоя (сверху вниз по порядку), а не по прямоугольнику.

## Покупка предметов (сцена 1)
- Связать с `scene_01.json`: «Лампа» → слои `lamp` и `lampglow`, «Полка» → `shelf`, «Коврик» → `rug`, «Шторы» → `curtains`. Пока не куплено — слой скрыт.
- «Обои» сейчас входят в слой `background` и отдельно не скрываются. Покупка обоев — только отметка, без смены картинки. Если нужен отдельный слой обоев, написать, его дорисуют.

## Герои
- В сценах уже есть слои `varya` (сцена 1) и `cat` / `catchair` / `catk` (Тимоша). На шаге «Живая сцена» слой `varya` скрыть и ставить героев из `characters/`.
- Рост: Варя занимает около 37% высоты кадра, когда стоит на переднем плане. Остальных масштабировать по `relHeight`.
- Говорящий герой: пузырь реплики над головой, без рамки-аватара.

## Проверка
- Собрать APK версии 0.2.0, вызвав `scripts\build-apk.ps1`. На телефон ставлю сам: USB-отладки нет.
- Для сверки сделать Compose `@Preview` трёх сцен и шага «Оформление» и показать скриншоты здесь, в Claude Code, рядом с `full.webp` каждой сцены. Коротко написать, что совпало, а что нет.
- Обновить docs/STATUS.md: что подключено и что осталось.

## Правила
Только этот этап. Без новых библиотек и больших загрузок. Картинки не пережимать и не менять размер. Пояснения короткие, простым языком.
