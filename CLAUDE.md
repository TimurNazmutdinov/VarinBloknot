# Варин блокнот

Офлайн Android-игра (Kotlin + Jetpack Compose, без material3). Полное ТЗ — `ТЗ.md` (читать по запросу, Grep по разделу). Список всех 56 сцен — `docs/scenes_all.md` (только Grep по номеру сцены).

## Правила проекта
- Весь текст сцен — только из `content/scenes/*.json`, в код не зашивать. Источник правды — папка `content/` (она же встроенный запасной контент в APK через `assets.srcDir`).
- Картинки в проекте только WebP (`content/art/`), в JSON они названы `.png` — приложение подменяет расширение.
- Раскладка экранов — «Мастерская» (рисунок сверху, инструменты снизу), светлая тёплая схема. Логика и UX — `docs/UX_v3.md` (утверждено), макеты — `design/sketches/v3.html`. Графика — слои из `content/art/<сцена>/layers.json` (ТЗ: `art_v2/ТЗ_графика.md`).
- Сборка и релиз — `docs/RELEASE.md`. Gradle на этом ПК требует `JAVA_TOOL_OPTIONS=-Djdk.net.unixdomain.tmpdir=C:\tmp` (скрипты задают сами).
- Скрипты `.ps1` — только ASCII в сообщениях (PowerShell 5.1).
- Эмулятор не запускать. Отладки по USB не будет: первую версию пользователь ставит на телефон вручную, дальше — только автообновление из самого приложения. Проверка экранов — по скриншотам, которые присылает пользователь.
